# Hey, I'm CoderJr.

**Small tools. Shared possibilities.**

This is my space to explore ideas, learn by building, and share useful things with everyone. I want to turn everyday problems into tools that make someone's day a little easier.

## What I'm here to build

- **Useful little tools** — less repetitive work, more time for what matters.
- **Creative experiments** — ideas you can try, remix, and make your own.
- **Open resources** — practical starting points for your next project.

## Have a problem worth solving?

Tell me about a task you wish were easier, a tool you wish existed, or an experiment you'd like to explore. You don't need to write code to bring a good idea.
